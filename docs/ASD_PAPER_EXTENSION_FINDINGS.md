# 七任务独立扩样：成本树的跨领域收益与边界

本轮已完成514个此前未用源任务、530个匹配输入，四方法9540次主计时、640次单参数控制、530条自然AR参考、64次真实自身历史第二轮。结果支持把成本受控树作为独立模块保留，也支持树与ASD在若干场景组合；收益并不局限于数学。MATH本轮退化、代码功能错误和MMLU输出合同损失全部保留。

## 可以接纳的结果

严格BudgetTree相对DFlash，在GSM/MATH/HumanEval/MBPP/MT-Bench/Alpaca的自然时延分别下降10.25%/6.19%/2.64%/14.87%/13.92%/17.15%；MMLU基本持平。全部530个匹配请求的自然输出与DFlash逐token、文本、停止一致；三种阶段共1590组对照均保持。这里保留的是DFlash的实际输出，另有一题与单token AR的有限精度分歧，详见审计。

树+ASD相对普通ASD，在新GSM/MBPP/Alpaca分别省7.72%/10.21%/17.89%，最终正确数分别114→117/128、31→32/64；Alpaca用独立偏好和局部性质评价。MT-Bench匹配单轮均题时延省5.51%，按16个对话合并两轮后省10.12%，真实自身历史双轮省12.93%；后两项的对话bootstrap时延比区间分别为[.8516,.9439]和[.8235,.9200]。两种历史的输入定义不同，分别报告。

HumanEval自然省3.26%但正确53→52/64；MATH自然慢5.50%（时延比区间[.9771,1.1418]），正确44→45/64；MMLU自然慢1.30%，只答字母的主合同正确39→37/114。这些结果没有要求所有数据都胜出，也没有将速度收益直接等同于质量保持。

## 自然停止和质量的边界

MATH逐题长度比均值上升11.08%，固定TPS只提高4.37%，共同128基本持平；40个双方保守主评分正确且EOS的事后交集仍慢6.14%。因此退化不能只归因于一题截断，也不能靠接受长度提高推断完整请求变快。math500:323的ASD为1537 token且最终1/3，组合循环到4096且无最终boxed答案；213则从正确2变为错误1。正向例156/224/328分别修正最终36度→30度、3/256→9/256、遗漏x=0造成的范围计数2→3；主评分没有事后改写。

HumanEval/MBPP/MMLU固定256结果中，组合分别约66.71%/80.43%/89.42%的token位于本轮实际出现EOS ID的首次位置之后。HumanEval的固定TPS+48.42%因此不能称为正常代码请求提速48%；自然只有3.26%且新增一个净测试失败。

六个ASD与组合之间发生变化的代码题，已用12次小型语义见证核对。组合失去HumanEval91（把Is当独立I）、99（−15.5被错舍为−17），得到103（均值取整修复）。MBPP190把严格内部点4错计9，333修复原地排序无返回值的测试合同，74补回不同输入长度的检查。全部按原测试记分，未用新反例重写主准确率；具体代码SHA和输入/输出见quality-audit.json。

MMLU四组逐题可提取的首选项相同，均78/114正确、105/114可提取。组合相对ASD的主合同变化为5失3得，来自额外文字/格式，不能偷偷将首选项诊断替换只答字母的主评分。

## 控制曲线与使用范围

640次预定控制覆盖两近似方法的B4/B12/g.125/g.5/M1，B0/B8复用主轨迹；每族仅前4源任务，MT展开为8轮。MATH切片中M1把B8的2/4正确、1截断改为3/4、0截断；其他配置不形成跨任务统一最优。HumanEval g.5固定TPS提高但自然仍退化，MMLU g.5主质量下降。这些是预定小切片诊断，不据此改主参数、挑赢家或宣称新的独立验证；开放控制输出保留，本轮未另评其RM偏好。

建议保留两条明确路径：严格成本树用于希望保持DFlash输出的场景；树+ASD用于接受已披露近似风险的GSM、MBPP及自由生成场景。MMLU的精确输出合同、HumanEval的功能错误以及MATH的长路径风险不作通用升级。旧Joint证据仍保留，不因本轮结果重命名为已验证的新优势。输入长度、AR输出长度和双方正确子集只用于后验解释，未训练路由；AR输出长度是未来信息，不能当作部署时已知标签。
