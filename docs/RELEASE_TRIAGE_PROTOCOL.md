# 发布说明影响初筛：小成本检验协议

2026-10-18，在本批任何模型输出之前固定。承接 CONFIG_REVISIONS_DIAGNOSIS 的最后一项候选，不重启原 CI 确认或 H 训练。本轮是可行性开发检查，不作独立泛化确认。

- 真实来源：Requests v2.32.3/4/5；HTTPX 0.26.0/0.27.0/0.28.0；Click 8.1.8/8.2.0/8.2.1；Flask 3.0.3/3.1.0/3.1.1；Starlette 0.45.0/0.46.0/0.47.0；Rich v13.9.0/v14.0.0/v14.1.0。每项目三个时间点，共 18 请求，版本按名称预先固定，非最新三次连续发布，不声称覆盖之间全部版本。所有版本早于 2025-09-01；按 tag 解析 commit 并核对 tag/commit 原始文件相同。仅保留该版完整 changelog 段落，不按内容、模型或重复率换样本。保留六项目最终所选 commit 的完整许可，来源及片段各自 SHA。Starlette 使用已核实迁移后的同一仓库 Kludex/starlette。
- 应用合同：把本次发布说明转成五类升级影响初筛 JSON：python_runtime、dependency、api_migration、security_fix、other_behavior。每类给 review/not_mentioned，并引用 1–2 个支持该判断的当前来源行 ID；not_mentioned 必须给空证据。它只是人工审查分流，不是完整升级计划或安全建议。没有证据不等于不存在影响，不允许输出“可以安全升级”。当前完整材料和所有定义给 Target；不喂旧完整答案、gold 或缺失的当前事实。
- 标签：运行前由开发 agent 阅读原文，按明确定义人工式逐例标注各类状态、允许的支持行及理由并冻结 SHA。它不是独立领域专家复核，不把标注者与评测代码的同源性隐瞒；模型不参与自评。定义将 Python 版本支持与仅在某版 Python 上启用的功能区分，将安全漏洞修复与一般 TLS 修复/安全特性区分，将依赖约束与延迟导入区分。API 迁移仅包括移除/弃用/改名/调用约定变化，不包括纯注解或新增可选能力。其他可观察功能行为排除已完全归入前四类的变化、文档/内部重构/纯类型修复。
- 阶段 1：只生成 Qwen3-8B Target AR 18 次，FP32/eager、greedy、非思考，沿用 target revision、4.57.3、A6000 GPU0、四线程。模型资产校验；输入预算 6144，输出预算 768；在任何推理前预检，不能因超长丢样本。每项目首轮冷历史，第二/三轮只含同项目更早回答；过去错误也保留，不用 gold 替换。逻辑请求顺序不冒称历史发布日的真实服务日志。每次请求全部材料当前可用；不访问后续版本或跨项目记忆。
- 质量门槛：18/18 无额外文本且 schema 合格、0 截断；至少 17/18 请求五类判断及支持证据全部正确；90 类至少 86 类正确；python_runtime/dependency/security_fix 的全部正例均须召回。错误证据、来源行越界、无事实支持、漏掉整个正类均算错。`not_mentioned` 不要求列出全部变更；review 只需 1–2 条充分证据，不宣称全部迁移事项覆盖。任一门槛失败则停止计时，不扫提示或改标签救结果。若标注真有错误，保留旧证据、修订数据版本后才可另议，不能覆盖本次结果。
- 阶段 2：在保存的 AR 输出上，做事后精确接续机会诊断，比较当前 prompt 与加合法过去回答。使用原 token IDs、长度 6 的精确锚点、最多 32 个接续；不跨记录/特殊 token。枚举来源位置选择最长正确接续，是离线 oracle 上限，忽略真实选源、路由、检索、KV 和 EOS 成本，不能宣称实际接受率或加速。计算长度至少 8 的接续可覆盖位置并集；额外历史独有覆盖是 Global 并集减 Context 并集。只看 12 个有历史请求，要求合计独有覆盖至少其输出 token 的 10%，且至少 4/6 项目独有覆盖达到 5%。18 个全部报告，不按质量或机会筛样本。不满足就停止。
- 只有前两门槛同时通过，才追加一次小规模端到端开发计时：12 个有历史请求 × DFlash/Context/Global/Arctic 四方法 × 单重复，最多 48 次；冷启动六例另列已有 AR 成本，不把它伪造成熟基线计时。沿用 R32/6/冷却1/待消费1024、简单 Global 和官方线性 Arctic 候选器，不新增 H/游标/训练。每方法隔离历史，用其此前相同 AR 轨迹建立初始回放状态；初始化/导入过去状态的准备成本单列，在线快照/冷索引/检索/prefill/所有前向/回切/解码/当前回答写回均计入。不把参考构造计为在线免费服务历史，也不把 AR 构造成本并入正式加速比。
- 计时仍需同 prompt、快照和 token 完全一致；首个不一致保存并停止。以 DFlash/Global >= 1/0.9（延迟至少降 10%）和 Context/Global >= 1/0.95（历史额外延迟至少降 5%）作开发投入参考，至少 4/6 项目较 DFlash 更快；不作小样本显著性或生产结论。与 Arctic 接近时不宣称新算法领先，只有明确的场景瓶颈才讨论额外机制；不要求打败所有方法。
- 数据、协议、标签和源码在 GPU 前冻结并推送，保存本次实际运行 source SHA；公开输出/结果保存，权重、数据库和原始整本 changelog 不上传。结束时给出继续或停止决定。质量/机会失败就以负结果结束这一次候选检查，不再自动轮换场景。
