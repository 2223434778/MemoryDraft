# R + DFlash 首轮接入与场景开发协议

2026-10-18。对应用户授权“写代码开干”。先完成 A 接入正确性和 B 小规模开发场景检查；这是开发探索，不是独立测试结论。

- 固定 Qwen3-8B、DFlash-b16 的既有 revision/代码/权重 SHA，Transformers 4.57.3、torch 2.5.1、A6000 GPU0、FP32/eager、非思考严格 greedy。沿用此前 manifest，新增循环适配保留 Z Lab MIT 许可。Target prompt、停止规则和预算同批相同。
- A：八项短检查，比较官方 DFlash、适配后关闭 R，以及诊断用强制切换；正常空历史、长度 1/2/31/48、首 token EOS 和两类 R/D 切换。所有结果逐 token 对齐 AR；测试才可用已知轨迹构造拒绝，性能实验禁止 oracle 候选。
- B：`development_projects()` 预声明 12 个合成开发项目，P1/P2/P3/边界各 3。P2 每项目三次顺序修订，因此共 18 个当前请求。每请求 1 次开发计时，方法顺序按种子交错；小样本单重复不作稳定速度结论。P1/P3 当前 prompt 已有旧产物，明确可能只有编辑加速；P2 当前 prompt 给完整配置事实但不粘贴过去输出。
- 先生成全部过去回答（预算768），保存再生成任何当前参考；冻结用户/项目 order。每轮当前 AR 只作评分，全部方法完成后才以相同最终文本写入下一轮过去记录。快照按当前时刻选择，方法间路由状态独立。过去回答达到预算时记录，不隐瞒截断。
- B 方法为 AR、官方 DFlash、Global（全局有界后缀查找+DFlash）、Cursor（增加连续游标/局部重新定位）、Context（与 Cursor 同策略，但只从当前 prompt 取候选）。Global/Cursor 使用同一合法历史加当前 prompt，保证相关对照资源相同。Context 用于测过去历史的独立作用。这里的 Global 是明确的机制基线，不冒称 SAM/SuffixDecoding 官方复现。
- 固定 R 提议上限32、准入匹配6、索引最小匹配3/最大32、位置扫描64、局部窗口96、一次拒绝后停用R一轮，待消费特征达到1024 token时强制Draft消费。初版按能否匹配选择，不实现复杂概率模型。所有参数在此次运行前固定，不根据本次输出追加参数搜索。
- 在线计入 tokenization、快照、索引构建、检索、模型 prefill/起草/验证、有效特征维护、解码和方法路由。每请求重建索引，报告冷成本，不假装已有在线缓存。模型加载、审计、公开预热和构造过去资产单独记录。
- 开发默认输出预算384（边界32/96），不因某方法长度修改。预算截断与 EOS 比例随结果报告。P2 若完整JSON达到预算，明确本次只是有限轨迹，不宣称完整产物验证。
- 禁用 R 的适配对照在 A 中检查；B 重点比较最小混合和游标增量。先发现适用场景，再冻结新项目验证；本轮不要求跨场景获胜，也不将开发赢家作为最终论文结论。
- 任一方法与固定 AR 不一致时保存失败、停止；不得放宽接受规则。开发记录包含 token IDs、prompt/snapshot hash、逐轮接受/提议、缓存前沿和查找来源。发布只限合成白名单结果，模型和数据库不入 Git。
