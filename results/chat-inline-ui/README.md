# 正文内实时投机简览验收

本轮是字体、菜单和推理过程显示改动，不是新算法或速度实验。`acceptance.json` 汇总浏览器、相关测试和发布身份；`gpu.json` 是四种方法观察开关的真实 GPU 配对结果。截图只包含隔离测试账号的合成问题。

默认正文 17px。黄色草稿直接跟随正文光标，实际接受片段在正文标绿，Target 补充标蓝，丢弃预览标红划线。生成结束后清除临时标记。完整树及轮次仍在右侧；右侧浏览旧轮次不改变正文的实时状态。

Python 检查覆盖 Unicode/UTF-16、真实树路径、上下文解码、输出上限和现有聊天／服务协议，共 60 项；JS 状态检查 5 项。浏览器真实生成覆盖 DFlash 代码和成本树中文回答，另检查菜单能力禁用、键盘、手机、减少动画、关闭展示与中途停止。未重跑全部研究基准或完整 Python 套件。

首个 GPU 配对运行的 token 比较通过，但计数／ASD metadata 严格比较失败，具体差异当时未保存。随后为断言增加诊断负载，四方法重跑严格通过；没有放宽比较条件。原失败原因尚未确定，不能解释为已经证明的编译或数值问题。菜单的即时焦点问题已修复并单独通过键盘复测。
