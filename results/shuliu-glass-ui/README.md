# 树流：玻璃界面与两个独立开关

网页标题、登录页、侧栏、输入提示、回复名称和favicon统一为「树流」，图标为原创树与水流。Python包名、数据库／Cookie及历史研究归档继续兼容原部署。

玻璃样式使用半透明表面、背景模糊、色彩与细高光边缘；选择菜单放到body顶层，避免模糊容器改变固定定位。圆形勾选框26px，透明原生输入命中区28px、标签至少44px高，保留键盘与焦点语义。默认勾选回弹0.28s，勾画过渡0.23s；减少动画时全部关闭。

「展示推理过程」只控制正文投机简览；顶部「展示详细推理过程」只控制详细侧面板。四种组合、生成中独立切换、两者关闭后再打开详情、完成后移除临时标记均在真实DFlash／成本树ASD生成中检查。为支持中途开启，投机网页请求会收集真实事件，即使两个视图都关闭仍存在观察成本。过程不进入后续模型prompt。

- `browser.json`：四组合、文本保存、手机320／390宽度、菜单定位及减少动画结果。
- `motion.json`：默认动画单独检查结果。最终组合运行继承了前一次测试的减少动画设置，故另显式开启默认动画验证；归档脚本入口已增加媒体状态重置，避免后续测试继承设置。
- `acceptance.json`：源码／ZIP身份、测试计数、发布结果和已观察问题。
- `browser-check.js`、`motion-check.js`：供Playwright CLI `run-code --filename=...`复用的检查脚本。需要自行准备与本轮一样的本地隔离测试网关及会话，不含凭据。
- 三张静态外观截图及一张真实生成截图，只含本地隔离账号的合成问题。

首次DFlash浏览器请求发生网关连接中断，服务端未记录生成失败，出现一次取消；具体根因未确定，后续组合运行通过。另修正了两个检查脚本问题：动画中的缩放尺寸被误当成最终尺寸，以及切回8B后仍处于AR而勾选框正确禁用。未放宽模型验证或网络超时来掩盖问题。

相关Python 46项、发布包SVG安装1项、前端状态10项通过。本轮没有重跑算法速度基准或完整Python套件。旧infra冻结分支／标签不移动，GPU模型不重载，网页输出上限仍为16384 tokens。
